# Game Boy Studio 0.6 — обычный Game Boy

Эта версия сосредоточена на чёрно-белом Game Boy (DMG). Ядро написано на C++20, приложение — на Win32, без SDL и дополнительных игровых библиотек. Поддержка Game Boy Color — следующий отдельный этап.

## Самый простой запуск

1. Распакуй архив целиком.
2. Запусти **START_WINDOWS.bat** либо **dist\GBStudio.exe**.
3. Сначала откроется наше демо. Нажми **Ctrl+O** и выбери свою игру `.gb`, либо перетащи файл игры в окно.

В GitHub готовая компактная сборка лежит в `releases/GBStudio-0.6-DMG-Windows-x64.zip`. Внутри неё приложение находится прямо в корне: **GBStudio.exe**. Исходники и компилятор для запуска этой сборки не нужны.

Mario, Tetris и другие коммерческие ROM-файлы не включены. Для проверки конкретного издания игры нужен соответствующий `.gb`; результаты аппаратных тестов приведены в **COMPATIBILITY.md**.

## Кнопки

| Действие | Кнопка |
|---|---|
| Движение | Стрелки |
| A и B | Z и X |
| Start и Select | Enter и Shift |
| Открыть игру | Ctrl+O |
| Перезапустить игру | Ctrl+R |
| Пауза | P |
| Сохранить / загрузить состояние | F5 / F9 |
| Полный экран | F11; Esc — выйти из полного экрана |
| Следующая палитра | F1 |
| Скриншот | F12 |
| Ускорение | Удерживать Tab |

Работает геймпад XInput: крестовина или левый стик, A/B, Start/Back. Приложение автоматически ставит игру на паузу при переключении на другое окно.

## Что реализовано

Процессор со всеми документированными командами, прерывания, HALT/EI, таймеры, память картриджей MBC1/MBC1M/MBC2/MBC3/MBC5, RTC, DMA, фон, окно и спрайты, приоритеты объектов, четыре звуковых канала, управление, полноэкранный режим и сохранения.

Кадр публикуется целиком, затем выводится через второй буфер окна. Эмуляция идёт с частотой оригинальной консоли: примерно **59,73 кадра/с**, без накопления лишних циклов между кадрами. Палитры меняют только отображаемые оттенки, а не модель консоли.

Сохранения самой игры `.sav` и часы `.rtc` записываются рядом с ROM автоматически при смене игры, закрытии приложения и каждые 30 секунд. F5/F9 используют отдельный файл `.state` и сохраняют состояние процессора, графики, звука, таймеров и DMA. Повреждённое состояние или состояние от другой игры отклоняется. Состояния старой версии 0.5 несовместимы с новым форматом; обычные `.sav` сохраняют прежний формат.

Скриншот сохраняется рядом с игрой как `имя_игры_screen.bmp`. Папка с игрой должна разрешать запись файлов.

## Если хочешь открыть код в Visual Studio

1. В Visual Studio Installer установи рабочую нагрузку **«Разработка классических приложений на C++»**.
2. Открой **GBStudio.sln** двойным нажатием.
3. Сверху выбери **Release** и **x64**.
4. Нажми **F5**: проект соберётся и запустится с демо.

Поддерживаются Visual Studio 2022 и 2026. Для сборки двойным нажатием есть **BUILD_WINDOWS.bat**: он сам находит установленный компилятор, собирает и проверяет ядро, затем создаёт `dist\GBStudio.exe`.

Основной код состоит из трёх файлов:

| Файл | Назначение |
|---|---|
| `src/gameboy.hpp` | Процессор, память, графика, звук и сохранения |
| `src/windows_main.cpp` | Окно Windows, звук, клавиатура и геймпад |
| `src/headless.cpp` | Запуск аппаратных тестов без окна |

## Как повторить внешние тесты

После CMake-сборки установи Pillow и запусти:

```powershell
py -m pip install Pillow
py tests/run_rom_tests.py --emulator build/Release/gb_headless.exe --download --mooneye
```

Программа загрузит тесты из закреплённых версий Blargg, Mooneye и dmg-acid2, выведет результат каждого и создаст `build/rom-tests.json`. Игры Nintendo она не скачивает.

## Следующий этап: Game Boy Color

Цвет — это новые банки памяти, атрибуты тайлов, цветовые палитры, двойная скорость процессора, HDMA/GDMA и другие аппаратные особенности. Их следует добавлять отдельной моделью и проверять CGB-тестами, сохраняя DMG-проверки. Пока картриджи только для Color отклоняются с понятной ошибкой; совместимые GB/CGB-картриджи запускаются как обычный Game Boy.
