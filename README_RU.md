# GameBoy Studio 0.8 — Game Boy / Color и Studio Mode

Нативный эмулятор Windows 10/11 x64 на C++20. Версия 0.8 расширяет ядро 0.7 инструментами для игры, сессий и отладки. Полный пользовательский список — программа дальнейшего развития, а не перечень уже готовых возможностей: точный статус приведён в **docs/FEATURE_STATUS_RU.md**.

## Запуск

Распакуйте архив целиком и запустите **GBStudio.exe**. В исходном архиве готовая программа находится в **dist/**, также есть **START_WINDOWS.bat**. Откройте `.gb` или `.gbc` через Ctrl+O либо перетащите ROM в окно. ZIP/GZIP пока нужно распаковать самостоятельно. Оригинальные демо проекта включены; коммерческие ROM и Nintendo Boot ROM не включены.

## Что работает

- Меню на русском/английском, темы игрового окна, шесть недавних игр, переназначение игровых клавиш, сохранение размеров/положения и восстановление сессии. Нативные меню и элементы Studio используют оформление Windows.
- Палитры DMG/Pocket/Light/чёрно-белая/сепия/amber/blue и редактор четырёх цветов. Названия Pocket/Light обозначают палитры отображения, а не отдельные модели оборудования.
- Необязательные LCD-сетка, CRT-строки и ghosting с выбором отклика. Сравнение исходного и обработанного изображения, integer scaling, полноэкранный режим. Обработка выполняется CPU/GDI в отдельном буфере и не меняет пиксели PPU; это пока не GPU-шейдеры.
- Девять быстрых слотов, именованные файлы, автосессия и сжатая перемотка в памяти. Глубина: выключено, 30 секунд, 2 или 5 минут; предел памяти 64 МиБ может уменьшить фактическую глубину.
- Скорости 0.25x, 0.5x, 1x, 2x, 4x, 8x и 16x; шаг кадра и пауза. Удержание Tab включает 8x.
- Запись и повтор ввода `.gbmovie` с начальным состоянием, идентичностью ROM и настройками каналов. Ввод записывается на границе кадра; нажатие и отпускание, целиком прошедшие между двумя кадрами записи, не сохраняются. Воспроизведение требует того же ROM, модели, совместимого формата состояния и boot-образа, если начальное состояние внутри загрузки.
- Внешние загрузочные ROM: DMG 256 байт; CGB 2304 байта или упакованные 2048. Выбор через Параметры → Внешняя загрузочная ROM перезапускает игру. CGB-режим для DMG-only картриджей пока явно отклоняется.
- WASAPI с отдельным потоком и lock-free SPSC, резервный waveOut, общая громкость, отключение четырёх каналов, задержки 20/40/80 мс и запись WAV. Ядро/запись — PCM16 stereo 44.1 kHz; преобразование к частоте устройства выполняет Windows. Выбор 48/96 kHz и FLAC пока отсутствует.
- Studio: шаг инструкции, SM83/CB дизассемблер, регистры, PC breakpoints, наблюдение изменений RAM, история команд и экспорт диагностического JSON. API дополнительно поддерживает условия и run-to. Watchpoint сравнивает значения между инструкциями: чтения и запись того же значения он не фиксирует.
- IPS/BPS применяются к отдельной копии в `Sessions/Patched/`; исходный ROM не меняется. BPS проверяет source/target/patch CRC32. У IPS нет встроенного хэша исходной игры. Есть библиотечный разбор Game Genie и GameShark type 01, но применение читов и менеджер ещё не готовы.
- Unicode CLI: отчёты ROM/header/CRC32, трасса, ограничение числа инструкций, остановы, дизассемблер и дампы памяти.

## Управление

| Действие | Клавиша |
|---|---|
| Движение, A, B | Стрелки, Z, X |
| Start / Select | Enter / Shift |
| Открыть / сброс | Ctrl+O / Ctrl+R |
| Пауза / кадр | P / F6 |
| Быстрое сохранение / загрузка | F5 / F9 |
| Выбор слота | 1–9 |
| Именованное сохранение / загрузка | Ctrl+Shift+S / Ctrl+Shift+O |
| Перемотка / турбо | Удерживать Backspace / Tab |
| Полный экран / исходный BMP | F11 / F12 |
| Studio | Ctrl+D |

XInput: крестовина/левый стик, A/B, Back/Start. Игровые клавиши меняются через Параметры → Управление. Эмуляторные горячие клавиши фиксированы. При потере фокуса обычная игра приостанавливается. Звук воспроизводится на 1x; другие скорости, пауза и перемотка без звука. WAV пишет исходный PCM и не зависит от громкости устройства. Каналы нельзя менять во время записи/повтора ввода; повтор восстанавливает записанный набор каналов.

## Файлы и настройки

Батарейные `.sav` и `.rtc` сохраняются рядом с ROM; предыдущая версия остаётся в `.bak`. Быстрый слот 1 — `game.gb.state` / `game.gbc.state`; слоты 2–9 — `game.gb.slotN.state`. Если новый файл слота 1 отсутствует, читается старый `game.state`. Именованные файлы можно хранить отдельно. GBSTATE5 включает ввод и состояние загрузки; GBSTATE3/4 читаются. Формат по-прежнему содержит структуры C++ и не заявляется переносимым между произвольными компиляторами/архитектурами. BESS пока нет.

`GameBoy-Studio.ini` рядом с программой хранится в UTF-16 и заменяется через `.tmp`. Если папка недоступна для записи, используется `%LOCALAPPDATA%/GameBoy-Studio/config.ini`. Автосессии лежат в соседней папке `Sessions/<ROM hash>.state`. Приложение работает офлайн, без телеметрии.

Документированные параметры раздела `[Studio]`:

| Ключи | Значения |
|---|---|
| Russian, Sound, IntegerScaling, Ghosting, ResumeSession, LightTheme, CompareDisplay, Maximized | 0/1 |
| Scale, Palette, Filter | Масштаб 1–8; палитра 0–7; эффект 0=нет/1=LCD/2=CRT |
| GhostWeight, Volume, AudioLatency | 10–80%; громкость 0–100%; задержка 20–80 мс |
| SpeedIndex, StateSlot, Model, RewindSeconds | 0–6; 1–9; 0=Auto/1=DMG/2=CGB; 0–300 секунд |
| WindowX/Y/Width/Height | Координаты и размеры окна |
| DMGBootROM, CGBBootROM, Recent0–5 | Пути загрузочных образов и недавних ROM |
| Key0–7 | Windows VK-коды: Right, Left, Up, Down, A, B, Select, Start |
| Color0–3, Mute0–3 | Цвета decimal RGB; отключение канала 0/1 |

## Сборка и проверки

Visual Studio 2022/2026 с «Разработка классических приложений на C++»: откройте **GBStudio.sln**, Release/x64. **BUILD_WINDOWS.bat --no-launch** собирает инструменты и GUI и запускает десять наборов тестов. CMake:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
cmake --install build --config Release --prefix dist
```

`tools/gb_headless.exe --help` показывает CLI. Например:

```powershell
tools/gb_headless.exe demo.gbc 60 --report report.json --output frame.ppm
tools/gb_headless.exe demo.gb --instructions 100 --trace trace.txt --trace-limit 100
tools/gb_headless.exe demo.gb --boot-rom my-dmg-boot.bin --model dmg
GBStudio.exe --self-test demo.gbc
```

Скрытый self-test запускает 12 кадров и 48 комбинаций отрисовки разных размеров, эффектов, тем и сравнения, проверяет неизменность видеобуфера. Это проверка кода, а не оценка удобства видимого интерфейса.

Внешние наборы воспроизводятся `tests/run_rom_tests.py` и `tests/run_cgb_tests.py` с `--download`; нужен Pillow. Данные конкретного прогона: **COMPATIBILITY.md**, **docs/validation-summary.json**, **docs/test-results.json**, **docs/cgb-test-results.json**. Новые тесты проверяют загрузку/FF50 на синтетических boot-ROM; оригинальные Nintendo образы не проверялись. Linux ASan/UBSan включаются через `-DGB_ENABLE_SANITIZERS=ON`.

Workflow GitHub собирает Windows, запускает Linux совместимость/санитайзеры и создаёт архивы с SHA-256. Релиз автоматически публикуется для отправленного `v*`-тега только после успеха всех проверок. Цифровая подпись требует сертификата владельца.
