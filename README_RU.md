# GB Studio Beta 0.5 — эмулятор Game Boy на C++20

**Это самостоятельное развитие загруженного пользователем проекта `gameboy_emulator_cpp20`: оставлен процессор LR35902, переписаны контроллер картриджа, видеосистема и ввод/вывод.** Эмулятор не содержит коммерческих игр или оригинального загрузочного ROM Nintendo.

## Как собрать и запустить на Windows 10/11

1. Распакуйте весь архив (не открывайте `.cpp` отдельно).
2. Установите **Visual Studio** с компонентом **«Разработка классических приложений на C++»** и **CMake**. Подойдут актуальные VS 2022 / VS 2026 с компилятором C++20.
3. Дважды щёлкните **`BUILD_WINDOWS.bat`**. Скрипт должен найти CMake в PATH, настроить и собрать проект, скопировать EXE в `dist/GBStudio.exe` и открыть программу. **Если CMake не найден**, откройте папку проекта через «Файл → Открыть → Папка» в Visual Studio, дождитесь конфигурации CMake и соберите конфигурацию Release. В Release-артефактах ищите `GBStudio.exe`.
4. Перетащите **`demo.gb`** в открытое окно или выберите **File → Open ROM...**. Это специально написанная для проекта бесплатная тестовая программа. Стрелки двигают квадрат. Для обычных игр используйте свои законно полученные `.gb` ROM-файлы.
5. В дальнейшем запустите EXE напрямую. Скрипт нужен только для пересборки.

**Важно:** GUI для Windows использует встроенные Win32/GDI + WinMM, установка SDL2, Qt, Python или дополнительных DLL для запуска EXE не нужна. В текущем окружении проверена сборка и выполнение *ядра в Linux*, а Win32-исполняемый файл здесь не компилировался. Поэтому эту сборку следует считать **тестовой бетой**, а не окончательно проверенным релизом для Windows.

## Управление

| Клавиша | Действие |
| --- | --- |
| Стрелки | Крестовина Game Boy |
| `Z` | A |
| `X` | B |
| `Enter` | Start |
| `Shift` | Select |
| `P` | Пауза |
| `Tab` (удерживать) | Ускорение (примерно до 5×, зависит от ПК) |
| `F1` | Сменить палитру экрана (4 варианта) |
| `F5` | Быстрое сохранение состояния (`.state`) |
| `F9` | Быстрая загрузка состояния |
| `F12` | Снимок экрана (`_screen.bmp`) |
| `Ctrl+O` | Открыть другую игру |
| `Ctrl+R` | Перезапустить текущую игру |

В меню можно включить/выключить звук, выбрать палитру и масштаб. Окно можно растягивать, картинка остаётся без размытия.

## Что действительно реализовано

- Эмуляция CPU LR35902 (основные документированные операции и CB-префикс), флаги, стек, прерывания, HALT и начальная поддержка HALT-bug.
- 160×144 пикселей, DMG-фон, окно, до десяти спрайтов в строке; построчный PPU с режимами 0/1/2/3, сигналами VBlank/STAT. Графика частично упрощена.
- DIV/TIMA/TMA/TAC с переходом по фронту таймерного сигнала и задержкой переполнения.
- Чтение кнопок и сигнал JOYP, передача байта OAM DMA во времени (ограничения доступа CPU не полностью воспроизведены).
- ROM-only, MBC1, MBC2, MBC3, MBC5. Частичная поддержка MBC3 RTC (включая приблизительное сохранение реального времени, без полной точности аппаратуры).
- SRAM-файлы `.sav` при наличии батареи, автосохранение примерно каждые 30 секунд и при закрытии/смене ROM.
- Быстрые состояния `.state`, с защитой от загрузки состояния другой игры, снимки экрана BMP.
- Win32 GUI: файловое меню, drag-and-drop ROM, пауза, ускорение, четыре палитры, сохранение, BMP, масштабирование.
- **Базовый приблизительный звук:** 2 прямоугольных канала, волновой и шумовой; настоящий APU ещё не эмулируется точно по тактам.
- Отдельная программа `demo.gb` для проверки собственного эмулятора без коммерческих игр.
- Тесты: **245 документированных основных кодов операций, 256 CB-кодов**, MBC1/2/3/5, таймер, видеорежимы, управление, быстрые состояния, демо.

## Чего пока нет / ограничения

- **Game Boy Color ещё НЕ поддерживается.** CGB-only ROM (заголовок `0x143 = 0xC0`) отклоняется. Игры, совместимые с обычным DMG, могут работать в чёрно-белом режиме, без возможностей Color.
- Совместимость со всем каталогом игр не подтверждена. Нужны тесты на конкретных ROM, исправление артефактов, точная синхронизация CPU-PPU и обработка сложных случаев HALT/STOP/HDMA (последнее для CGB).
- Нет аппаратно точного PPU FIFO, спрайтовых задержек, bus contention, точного поведения DMA, пиксельного тайминга или корректного синтеза APU. Нельзя честно называть этот проект «100% совместимым».
- Звук приближённый, некоторые игры могут быть беззвучны или звучать неправильно.
- Нет SGB, кабеля Link, сетевого мультиплеера, Game Boy Printer, инфракрасного порта, MBC6/MBC7, наклонного сенсора и Rumble.
- Состояния `.state` экспериментальные и пока не гарантируют совместимость между разными версиями эмулятора.
- Windows GUI пока не проверен на реальном ПК Windows в текущей среде. Если VS выдаст ошибку, текст ошибки и логи сборки помогут её устранить.

## Как добавить Game Boy Color (следующие этапы)

1. Ввести режим `DMG`/`CGB`, разные boot-регистры и проверку совместимости картриджа.
2. Добавить **2 банка VRAM** (`VBK`), **8 банков WRAM** (`SVBK`), атрибуты плиток/спрайтов и приоритеты.
3. Реализовать CGB-палитры BGPI/BGPD, OBPI/OBPD и настоящее 15-битное RGB-цветопреобразование.
4. Реализовать `KEY1` (двойная скорость), GDMA/HDMA, новые регистры и поправить тактовую синхронизацию таймеров/PPU.
5. Развернуть аппаратные тесты `dmg-acid2`, `cgb-acid2`, `mooneye-test-suite`, `blargg` и устранить обнаруженные ошибки.

Перед Color желательно стабилизировать DMG-ядро и сделать точный APU — тогда не придётся исправлять две платформы одновременно.

## Структура проекта

```
GB-Studio-Beta/
  BUILD_WINDOWS.bat         двойной клик для сборки в Windows
  CMakeLists.txt            проект VS / CMake
  src/gameboy.hpp          процессор, память, MBC, PPU, APU, состояния
  src/windows_main.cpp     Win32 окно, меню, звук, управление
  src/headless.cpp         проверка ядра без GUI (Linux)
  tests/core_tests.cpp     245+256 команд и подсистемы
  tests/make_demo.py       генератор своей тестовой ROM (нужен Pillow)
  demo.gb                  готовый тестовый ROM
  README_RU.md             это руководство
```

### Сборка тестов в Linux

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
./build/gb_headless demo.gb 120
```

Это **обучающий проект и перспективная бета**, а не замена зрелым эмуляторам уровня SameBoy или BGB. Все файлы написаны в рамках этого проекта; код собран без необходимости скачивать сторонние зависимости.
