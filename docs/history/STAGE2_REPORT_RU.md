# GameBoy Studio — результат второго этапа

14 октября 2026, Windows 10 x64. **Исправлены четыре расхождения Mealybug; осталось семь и три Boot-проверки.** Подготовлена новая DLL ядра вместе с исходниками. Сборка первого этапа сохранена отдельно.

## Исправления PPU

| Тест | CGB C: было → стало | CGB D: было → стало |
|---|---|---|
| `m3_lcdc_obj_size_change_scx` | 15 → 0 пикселей | 15 → 0 пикселей |
| `m3_wx_4_change_sprites` | 10 → 0 пикселей | 10 → 0 пикселей |

Для CGB адрес младшей плоскости спрайта фиксируется за один dot до чтения VRAM; изменение LCDC размера на следующем dot больше не меняет этот адрес. Чтение данных, общая длительность fetch, учёт циклов и исходный момент проверки отмены fetch сохранены. Поведение выбрано по [исходнику Mealybug](https://github.com/mattcurrie/mealybug-tearoom-tests/blob/master/src/ppu/m3_lcdc_obj_size_change_scx.asm) и подтверждено эталонами CGB C/D. Чтение DMG остаётся в прежней фазе.

Повторное совпадение WX во время уже активированного окна теперь вставляет нулевой BG-пиксель также на CGB. Убрано только исключение CGB; проверки fetcher/FIFO/состояния окна сохранены. Случай подтверждён [тестом WX со спрайтами](https://github.com/mattcurrie/mealybug-tearoom-tests/blob/master/src/ppu/m3_wx_4_change_sprites.asm) и [описанием Pixel FIFO](https://gbdev.io/pandocs/pixel_fifo.html#the-window). Условий по имени ROM, хешу или конкретной строке LCD нет.

Оба изменения сначала проверены отдельно: каждое исправило только свою пару CGB C/D, не изменив остальных результатов. Объединённое ядро затем проверено полностью.

DLL требует только системные `KERNEL32.dll` и `msvcrt.dll`; установка GCC для запуска не нужна. C ABI остаётся версии 3.

В GitHub Actions добавлены загрузка фиксированного набора ROM с проверкой SHA256, целевые PPU-регрессии и полный extended-прогон с семью открытыми FAIL. Сам GitHub Actions и Linux/sanitizer сборки здесь не запускались.

## Старые сохранения

Внутренняя версия состояния SameBoy изменена **16 → 17**, поскольку появился новый continuation point, а адрес OBJ уже зафиксирован при возобновлении следующего шага. Это предотвращает точное восстановление несовместимого старого внутреннего состояния.

Реальные снимки ядра v16 на DMG/CGB C/D успешно импортированы через содержащийся в них BESS; WRAM-маркер сохранён. Старые снимки без BESS отклоняются. **Импорт старых состояний не сохраняет точные прежние фазы PPU/DMA/APU.** Для старых TAS/детерминированных повторов оставьте сборку этапа 1. Новые состояния v17 проверены на точное продолжение, в том числе до и после нового latch.
