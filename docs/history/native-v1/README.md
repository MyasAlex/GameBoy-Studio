# Historical native Studio release v1

These reports describe the earlier `GameBoy-Studio-Native.zip` release. They are retained unchanged as the baseline for the accuracy update. They do not describe the source or Windows binaries in the current release.

That release passed the basic DMG 130/130 and CGB 15/15 collections. The extended collection passed 25/149: SameSuite 22/78, Mealybug DMG 1/24, CGB-C 1/27 and CGB-D 1/20. The expanded GBMicrotest/Mooneye exploration was introduced later and is not part of these old reports.

The baseline core header SHA-256 was `94ea21cdb3064f0d7950f80bd1070b51e2d0cbfcab57788ad888c8b28586e790`. Current source spans multiple files; use the current release source manifest instead of this old header hash.
