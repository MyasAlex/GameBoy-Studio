# GameBoy Studio — полный список улучшений для создания одного из лучших эмуляторов Game Boy на Windows

Цель — превратить GameBoy Studio из обычного эмулятора в полноценную ретро-платформу с высокой точностью, красивой графикой, отличным звуком, удобным интерфейсом, поддержкой аксессуаров, сетевой игрой и профессиональными инструментами разработчика.

Основная платформа — Windows 10/11, x64, язык — C++20, публикация исходного кода и готовых сборок — на GitHub.

## 1. Максимальная точность эмуляции Game Boy и Game Boy Color

- Полностью реализовать процессор Sharp SM83 (LR35902), включая все инструкции, флаги, прерывания и особенности HALT/STOP.
- Обеспечить максимально точные тайминги CPU, PPU, APU, таймеров и DMA.
- Переработать PPU с полноценным FIFO-конвейером и точностью до отдельных тактов.
- Реализовать аппаратные особенности DMG, Pocket, Light и разных ревизий Game Boy Color.
- Добавить поддержку внешних оригинальных Boot ROM.
- Обеспечить правильную работу цветовых палитр Game Boy Color для старых монохромных игр.
- Реализовать полноценные OAM DMA, HDMA, GDMA, особенности VRAM и WRAM.
- Исправить все возможные проблемы с прокруткой, оконным слоем, приоритетами спрайтов и растровыми эффектами.
- Реализовать корректную эмуляцию двойной скорости CGB.
- Поддержать ROM-only, MBC1, MBC1M, MBC2, MBC3, MBC5, MBC6, MBC7, MMM01, HuC1, HuC3 и другие контроллеры.
- Добавить RTC с корректным сохранением времени.
- Поддержать rumble-картриджи, датчики наклона и нестандартное оборудование.
- Обеспечить точную работу последовательного порта и инфракрасного интерфейса.
- Добавить аппаратные особенности Super Game Boy и Super Game Boy 2.
- Проверять совместимость на тестах Blargg, Mooneye, SameSuite, Mealybug и других наборах.
- Проверять реальные игры, включая Mario, Tetris, Pokémon, Zelda, Metroid, Kirby и сложные технические homebrew-проекты.
- Создать автоматическую базу результатов совместимости с играми.

## 12. Необычные функции, которые могут выделить проект

Здесь уже можно выйти за пределы обычного эмулятора.

Режим виртуальной консоли. Отрисовывать экран внутри трёхмерного или стилизованного корпуса Game Boy, Pocket или Color. Добавить виртуальные кнопки, подсветку, анимацию включения и звуки управления. При этом игровой процесс остаётся обычной точной эмуляцией.

Интерактивная временная шкала. Пользователь сможет просматривать недавние состояния игры, возвращаться в конкретные моменты и создавать контрольные точки с комментариями.

Режим сравнения оборудования. Одновременно запускать одну игру на виртуальных DMG и CGB и сравнивать палитры, графику, звук и тайминги. Особенно полезно для разработчиков.

Анализатор совместимости. Эмулятор определяет особенности ROM, предупреждает о потенциально неподдерживаемых устройствах и формирует технический отчёт. Диагностика должна опираться на реальные проверки, а не на предположения.

Запись прохождения с воспроизведением. Вместо хранения огромного видео записывать ввод и контрольные состояния. Это позволит воспроизводить игровые сессии и находить ошибки, если эмуляция детерминирована.

Система пользовательских расширений. Плагины для графики, отладчика, дополнительных панелей и интеграций. С доступом к ядру через документированный API, а не через произвольное изменение памяти.

Режим TAS. Инструменты для покадрового управления, записи ввода, повторного воспроизведения, создания контрольных точек и анализа игрового процесса.

Библиотека homebrew. Отдельный каталог свободно распространяемых игр с описаниями, скриншотами и информацией о лицензии. Это позволит демонстрировать возможности эмулятора без включения коммерческих ROM.

Проверка точности. Отдельное окно, показывающее результаты тестов CPU, PPU, APU, DMA, картриджей и сохранений для конкретной версии GameBoy Studio.

Система профилей оригинального оборудования. Возможность выбирать точную модель консоли, а не просто Game Boy или Game Boy Color, и видеть, какие аппаратные особенности включены.
