## Исправления ядра и сохранений

CGB TILE_SEL теперь учитывает обе границы переключения, корректный адрес signed-области на CGB-D и отдельно сохраняет фактический байт VRAM-шины, который может отличаться от искажённого пиксельного значения. Пакетный и пошаговый рендереры сохраняют согласованное состояние шины. Отключение окна DMG проверяется в фазе чтения индекса тайла; поздний WX соответствует выбранному LCD-профилю DMG-blob. Ревизия CPU сама по себе не определяет все физические варианты LCD; совпадение со всеми другими экземплярами DMG не заявляется.

Семь прежних расхождений — 8, 520, 186, 8, 260, 179 и 43 пикселя — стали нулевыми. ROM, эталоны и выбор моделей не заменены. Проверка регрессий дополнительно контролирует SHA256 эталона и модель, помимо SHA256 ROM. Подробности DMG — [STAGE4_PPU_WINDOW.md](STAGE4_PPU_WINDOW.md).

Внутренняя версия состояний повышена с **17 до 18** из-за нового регистра шины. Проверены отдельные значения шины и пиксельного latch, точное продолжение, быстрый/пошаговый PPU и настоящий fixture старого формата 17. Он импортируется через BESS, а не как совместимое native-состояние. Старые состояния без BESS отклоняются. Импорт старой версии не сохраняет прежние точные фазы PPU/DMA/APU; для старых TAS/детерминированных повторов нужна прежняя сборка. Происхождение fixture: [README](../tests/fixtures/README.md).

После свободной replacement firmware DMG/MGB устанавливается документированная фаза входа в картридж: LCD line 153, dot 396, DIV `$ABCC`, согласованный serial clock. Периферия действительно доводится до нужной LCD-фазы; ROM не распознаётся по имени или хешу. Пользовательская внешняя прошивка сохраняет собственное поведение. Исправлено также перекрытие загрузочной прошивки обработчиком MBC6. Оригинальные Nintendo Boot ROM не загружались и не выполнялись; точные начальные внутренности APU остаются непроверенными. См. [BOOT_HANDOFF.md](BOOT_HANDOFF.md).

## Игры

Корпус содержит 20 полноценных опубликованных свободно распространяемых игр, а не аппаратные тесты или собственные демо. Для восьми игр выполнены оба режима DMG/CGB: всего **28 прогонов по 2400 кадров**, примерно 40,18 эмулированной секунды каждый. Хеш каждого ROM, источник, лицензия и сценарий ввода зафиксированы; коммерческие ROM не скачивались и в архив не входят.

Все 28 запусков завершили проверки состояния/изображения; точное продолжение сериализованного состояния прошло 28/28. В 20/28 ветвлений ввод изменил изображение и WRAM; отсутствие изменения в остальных восьми ветвлениях не скрыто. Батарейная RAM записалась и точно перечиталась во всех 17 применимых случаях; в 14 из них RAM действительно изменилась во время прогона. Это проверка сохранённых байтов, не подтверждение полного игрового прогресса или каждой функции сохранения игры.

Побайтное совпадение PCM после загрузки состояния не подтвердилось: 0/28. В отдельных случаях отличие состоит только в количестве завершающих нулевых сэмплов; в других отличаются значения. История выходного ресэмплера/фильтра не сохраняется полностью. Метрики исходного и восстановленного звука остаются в отчёте; слышимое качество этим не оценивалось.

Прогоны не являются полными прохождениями, проверкой большой коммерческой библиотеки или гарантией совместимости. Покадровые снимки позволяют отличить меню, паузу, игровой экран и переходы. Дополнительные два прогона Tobu Deluxe до 3000 кадров показали возврат игрового изображения после одноцветного DMG-кадра 2400; постоянное зависание не воспроизвелось. См. [результаты игр](stage4-game-results.json) и [подробный разбор](STAGE4_GAME_COMPATIBILITY_RU.md).

Опубликованный PlantBoy выявил отклонение корректного 16 КиБ homebrew. Теперь исходный ROM без дополнения байтами принимается для контроллеров `00/08/09`; banked ROM размером 16 КиБ по-прежнему отклоняется как усечённый. Проверены raw, ZIP и GZIP пути, контроль размеров и сохранение ранее загруженного ROM при ошибке.

## Windows и открытые условия релиза

Исправлены фоновый наклон, зависание виртуальных кнопок после потери фокуса, сброс захвата мыши другого окна и вибрация в фоне. `--ui-self-test` проверяет настоящие сообщения видимых Win32-окон; чтения XInput и клавиш наклона подменены детерминированными функциями. Физические контроллеры этим не проверены. Снимок [реального окна программы в Wine](stage4-wine-gui.png) подтверждает вывод CGB-демо через GDI; его скорость в общей среде не доказывает производительность Windows.

Полноценная ручная проверка Windows 10/11, Direct3D/драйвера, слышимого звука, смены аудиоустройств, физических геймпадов/вибрации/наклона и webcam остаётся **NOT_RUN**. Подготовлен исполняемый протокол из 18 пунктов; он не проставляет PASS автоматически. Инструкция — [WINDOWS_MANUAL_QA_RU.md](WINDOWS_MANUAL_QA_RU.md), фактический незаполненный протокол — [stage4-windows-manual-qa.json](stage4-windows-manual-qa.json). Сборка не подписана; стабильный релиз не объявляется.

## Воспроизведение

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
python tests/fetch_extended_suite.py --output build/extended-suite
python tests/run_extended_tests.py --emulator build/gb_headless --suite build/extended-suite --report build/extended-results.json
python tests/run_rom_tests.py --emulator build/gb_headless --download --mooneye
python tests/run_cgb_tests.py --emulator build/gb_headless --download
python tests/fetch_game_corpus.py build/game-corpus
python tests/run_game_compatibility.py --executable build/gb_game_compatibility_runner --corpus build/game-corpus --output build/game-results --frames 2400 --jobs 2
```

Для запуска готовой Windows-сборки распакуйте весь архив и откройте `START_WINDOWS.bat`. Для автоматической и ручной приёмки используйте `RUN_WINDOWS_QA.ps1` и `RUN_WINDOWS_MANUAL_QA.ps1`; подробности есть в инструкции Windows. Удалённый GitHub Actions в этой сессии не запускался.
