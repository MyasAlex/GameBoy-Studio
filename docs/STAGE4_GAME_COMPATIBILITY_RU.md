# Реальные игры: воспроизводимая проверка от 18 октября 2026

Получены и реально запущены 20 свободно распространяемых homebrew-игр (19 семейств: оригинальная Tobu Tobu Girl и Deluxe считаются отдельно). Это опубликованные игры, а не аппаратные тесты или технические демо. Выборка содержит ROM-only, MBC1, MBC3 и MBC5, 18 запусков DMG и 10 CGB. Для каждой игры сохранены источник, лицензия, размер и SHA-256: [manifest.json](../tests/game_corpus/manifest.json). ROM-файлы в пакет результатов не включены.

Каждый из 28 запусков выполнил 2400 кадров — примерно 40,18 секунды эмуляции (около 18,75 минуты суммарно). Использован штатный AccuracyCore без внешней Nintendo Boot ROM. Ввод задаётся событиями контроллера; память игр не патчится. Дополнительно выполняются две 120-кадровые ветки для ввода и сохранения/восстановления.

- 28/28: процесс завершился без ошибки, наблюдались разные кадры; внутреннее состояние после 120 кадров воспроизведено точно.
- 20/28: конечный кадр и WRAM в контрольной ветке ввода отличаются от бездействия. В восьми остальных эта проверка не подтверждает реакцию: совпадение после полного цикла кнопок само по себе не означает неисправность ввода.
- 17/17 применимых запусков: SRAM записана и точно прочитана новым экземпляром ядра. В 14 из них SRAM изменилась относительно загрузки. Это проверка сохранения памяти картриджа, а не подтверждение всех игровых сохранений.
- 25/28: получен ненулевой PCM. В 2048gb и двух режимах GB-Wordyl данный сценарий звуков не вызвал.
- 0/28: PCM после загрузки состояния совпадает побитово с исходным продолжением. В отчёте сохранены число отсчётов, максимум и RMS различий. Состояние выходного ресэмплера/фильтра полностью не сохраняется; точность внутренних save-state не доказывает точность звукового продолжения. В некоторых случаях различается только длина на один стереоотсчёт.

Код возврата 0 у этого инструмента означает только успешную проверку состояния и смены кадров. Он не утверждает полную совместимость игры. Просмотрены 168 сохранённых кадров; ниже записаны конкретные наблюдения, включая паузы, меню, одинаковые кадры и одноцветный кадр.

Визуальная выборка показывает запуск игровых сцен и ограниченное взаимодействие. Полное прохождение, совместимость с коммерческой библиотекой, Nintendo Boot ROM, Windows-интерфейсом и физическими устройствами не заявляются. WAV-файлы подтверждают генерацию звука ядром; они не проверяют WASAPI, драйвер, динамики или гарнитуру. Одноцветный конечный кадр Tobu Tobu Girl Deluxe DMG и статичные поздние кадры Libbet оставлены видимыми в исходных артефактах.

Найденная практическая ошибка загрузчика исправлена: PlantBoy распространяется как 16-КиБ unbanked ROM, который ранее отвергался ограничением 32 КиБ. Теперь ровно 16 КиБ допускаются для типов 00/08/09 без изменения исходных байтов, в том числе через ZIP/GZIP. 16-КиБ banked ROM и неполные банки отвергаются. Добавлены проверки загрузки, отображения банков, отказа без замены активного ROM и архивных маршрутов в core/loader-тестах.

Воспроизведение:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --target gb_game_compatibility_runner gb_core_tests gb_loader_fuzz_tests -j2
python tests/test_game_corpus_harness.py
python tests/fetch_game_corpus.py /tmp/gb-game-corpus
python tests/run_game_compatibility.py --executable build/gb_game_compatibility_runner --corpus /tmp/gb-game-corpus --output /tmp/gb-game-results --frames 2400 --jobs 3
python tests/render_game_evidence.py /tmp/gb-game-results docs
```

Рендер контактного листа требует Pillow; запуск и сбор численных результатов используют стандартную библиотеку Python. Загрузчик корпуса скачивает только зафиксированные файлы и проверяет SHA-256. Harness удаляет старые артефакты, проверяет идентичность отчёта и стабильность исполняемого файла, чтобы не повторять прежний успех при неудачном новом запуске.

Зафиксированная ревизия корпуса: `50293559a496a3e20382fbf6a2e84b70ec622f88`.

Исполняемый файл этой проверки: `e36197e885be7ec004e44a90dc6c548bd5a589f01b9f73cef46ce6dbb15fe7d9` (SHA-256).

## Дополнительная проверка одноцветного кадра Tobu Deluxe

После основного корпуса выполнены два отдельных прогона той же сборки и ROM до 3000 кадров, DMG и CGB. Сценарий ввода не изменён; новые исходные данные и хеши записаны отдельно от основной выборки 28×2400. На кадре 3000 DMG снова показывает уровень с персонажем и противниками (4 цвета), CGB также показывает игровой уровень (17 цветов). Постоянное зависание после одноцветного кадра 2400 не воспроизведено; точная причина переходного кадра не установлена. Оба дополнительных прогона завершили проверку состояния успешно.
