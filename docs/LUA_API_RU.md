# Lua и пользовательские скрипты

Запуск: **Studio / Help → Run Lua script**. Скрипт применяется к загруженной
консоли. Остановка: **Stop Lua script**. Последний вывод `print` виден в Studio.
Скрипт может иметь функцию `on_frame()`, вызываемую после каждого кадра.

```lua
function on_frame()
    local lives = gb.read(0xC123)
    if lives < 3 then gb.write(0xC123, 3) end
end
```

Это пример API с условным адресом; он не заявлен как чит конкретной игры.

| API | Действие |
|---|---|
| `gb.read(address)` | Прочитать отображаемую память, включая ROM |
| `gb.write(address, byte)` | Записать в RAM/I/O; запись в ROM запрещена |
| `gb.joypad(mask)` | R, L, U, D, A, B, Select, Start: биты 0–7 |
| `gb.frame()` | Номер завершённого кадра PPU |
| `gb.registers()` | Таблица AF, BC, DE, HL, PC, SP |
| `print(...)` | Ограниченный журнал в окне Studio |

Встроена Lua 5.4.8. Доступны base, table, string, math и utf8. Память ограничена
8 МиБ, выполнение — 100 000 инструкций на вызов. Файловые/сетевые API,
`os`, `io`, `package`, `debug`, загрузка кода, `pcall`, `xpcall` и метатаблицы
не доступны. Это предотвращает обход ограничения времени через обработчик
ошибки или финализатор. Скрипт, превысивший предел, останавливается.

Скрипты меняют состояние игры; их не следует включать при проверке аппаратной
совместимости. Нативного ABI для DLL-плагинов в этой версии нет.


В 1.0 до восьми плагинов работают одновременно в отдельных VM. Выбор Plugins включает/выключает конкретный файл; Run Lua заменяет набор одним скриптом. Ошибка отключает только проблемный плагин. Файлы запускаются вручную; доступ к ОС/файлам/сети/native modules отсутствует. При Hardcore, TAS replay и сетевой игре плагины отключаются.
