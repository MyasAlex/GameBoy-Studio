# Начните здесь

Эта версия использует собственное C++-ядро Studio из `src/gameboy.hpp`, `src/native_ppu.hpp` и `src/native_apu.hpp`, без SameBoy и DLL эмулятора.

Распакуйте весь архив и откройте `START_WINDOWS.bat` или `dist\GBStudio.exe`. Готовая Windows x64-сборка находится в `dist`, компилятор для запуска не требуется. Чтобы пересобрать её из исходников, установите Visual Studio с C++/CMake и выполните `BUILD_WINDOWS.bat --no-launch`.

[README_RU.md](../README_RU.md) описывает управление и данные. [NATIVE_CORE_RU.md](NATIVE_CORE_RU.md) объясняет переход на собственное ядро и ограничения. Текущие результаты проверки сохраняются отдельно в `native-validation.json`. Отчёты прежней SameBoy-сборки являются историческими и не подтверждают совместимость этой версии.

Батарейные данные хранятся в `.sav`/`.rtc`. Новые снимки используют GBSTATE8 или BESS/GBSP3; GBSTATE3–7 и GBSP2 импортируются с восстановлением отсутствующих фаз. Для точного продолжения нужны совместимая сборка и одинаковый аппаратный профиль. Копию старых сохранений стоит оставить отдельно.

Улучшения точности и измерения описаны в [NATIVE_ACCURACY.md](NATIVE_ACCURACY.md). Коммерческие игры, оригинальные Nintendo Boot ROM, личные сохранения и аккаунты в архив не включены. Windows GUI и физические устройства требуют проверки на Windows. Стопроцентная совместимость всех игр не заявляется.
