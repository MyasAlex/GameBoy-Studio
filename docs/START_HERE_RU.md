# Начните здесь

Распакуйте весь архив, откройте START_WINDOWS.bat. Для изменения кода: GBStudio.sln в Visual Studio с C++/CMake или BUILD_WINDOWS.bat. Рядом с EXE нужны DLL ядра и helper фильтров; они включены.

README_RU.md объясняет управление, сеть, аксессуары и пути сохранений. FEATURE_STATUS_RU.md содержит фактический статус всех требований. validation-1.0.json и 1.0-*-results.json содержат результаты проверки. Старые отчёты 0.8/0.9 относятся к старому ядру.

Этот архив не содержит коммерческие игры, оригинальные Boot ROM, личные сохранения или аккаунты. EXE/DLL пока без подписи. Нативный Windows-прогон можно записать через RUN_WINDOWS_QA.ps1.
