# GameBoy Studio 1.1.0 — Studio Core

Версия 1.1 использует собственное ядро Studio без SameBoy и DLL эмулятора. Исправлены звук при включении APU на высоком DIV, фильтр Pocket/Light, стартовые регистры нескольких моделей и поведение окна LCD. Поддержаны ROM-only образы 16 КиБ, включая ZIP/GZIP. Сохранены более новые исправления ввода и фокуса из GitHub.

Измерения: 145/145 базовых аппаратных проверок, SameSuite 67/78, расширенный набор 73/149 (ранее 25/149). Дополнительная матрица: 337/482 GBMicrotest и 88/89 Mooneye CGB/AGB; 31 ручная проба остаётся INCOMPLETE. Пять отдельных проверок стартовых регистров моделей проходят.

Полная совместимость пока не достигнута: оставшиеся ошибки таймингов и динамического окна перечислены в отчётах. Старые GBSTATE3–7 и GBSP2 импортируются; новые снимки используют GBSTATE8/GBSP3. Исходные лицензии и сведения об авторах сохранены.

Для запуска скачайте **GameBoy-Studio-1.1.0.zip**, полностью распакуйте и откройте `dist/GBStudio.exe`. В комплекте исходники, проверенная Windows-сборка и отчёты. Автоматические GitHub-архивы Source code содержат только исходники.
