# Поэтапная работа над GameBoy Studio

Работа разбита на небольшие этапы. Реализованная функция, автоматическая проверка и проверка на реальном оборудовании учитываются отдельно.

Этап 1 выполнен. На этапе 2 закрыты четыре расхождения `m3_lcdc_obj_size_change_scx` и `m3_wx_4_change_sprites` на CGB C/D; осталось семь Mealybug-расхождений. По сообщению пользователя об ускорении этап 3 посвящён планировщику Windows: исправлен долг времени после Turbo, добавлены возврат к 1× и измерение темпа. Постоянное ускорение на доступных ROM не воспроизвелось; выполнено 6/6 замеров со звуком и без. Подробности — [STAGE3_REPORT_RU.md](STAGE3_REPORT_RU.md).

| Этап | Задача | Условие завершения |
|---|---|---|
| 1 | Нативная сборка Windows, достоверные тесты, сохранения и воспроизводимый отчёт | Сборка MSVC, внутренние проверки, SameSuite, явное завершение Mealybug, QA встроенных демо |
| 2 | Исправления PPU небольшими группами | OBJ-size/SCX и WX/sprites закрыты на CGB C/D. Далее — выбор тайлов LCDC, его вторые варианты и окно DMG. Каждый исправленный случай должен совпасть с эталоном без новых регрессий |
| 3 | Темп игры по сообщению об ускорении | Исправления планировщика выполнены; C++-регрессии и 6/6 замеров реального Windows-цикла прошли. Проверка конкретной проблемной игры остаётся открытой |
| Далее | Продолжение PPU | `m3_lcdc_tile_sel_change` и `m3_lcdc_tile_sel_win_change` на CGB C/D; затем остальные Mealybug FAIL |
| Позже | Boot и реальные игры | Повторить три Boot-теста с предоставленной оригинальной DMG-прошивкой; проверить предоставленные игры, сохранения и Link, включая обмен Pokémon |
| Позже | Интерфейс, графика, звук и устройства Windows | Проверить меню и горячие клавиши, GPU/шейдеры/resize, задержку звука, геймпады, вибрацию, камеру, Printer/IR и LAN/WAN |
| Позже | Внешние сервисы и выпуск | Подтвердить официальный RetroAchievements/Hardcore, проверить обновления и Discord, подписать сборку предоставленным сертификатом и подготовить GitHub release |

Следующий этап начинает работу с конкретной группы PPU-тестов. Положительные результаты тестов не заменяют проверки реальных игр или устройств. Оригинальные прошивки и коммерческие игры в архив не включаются.
